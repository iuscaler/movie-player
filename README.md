# 동영상 플레이어

Windows 용 동영상 플레이어

C++ / Win32 + [libmpv](https://mpv.io/manual/master/#embedding-into-other-programs-libmpv) 기반입니다.

## 빌드

Visual Studio 2026의 "C++를 사용한 데스크톱 개발" 워크로드가 필요합니다. libmpv는 처음 구성할 때 `third_party/`에 자동으로 받습니다.

- **Visual Studio:** 이 폴더를 열고(폴더 열기) 구성 `Visual Studio 2026 (x64)`를 선택한 뒤 빌드합니다.
- **명령줄(Developer PowerShell):**

  ```powershell
  cmake --preset vs2026-x64
  cmake --build --preset release
  ```

## 실행

```powershell
build\Release\MoviePlayer.exe "동영상 경로"
```

경로를 주지 않으면 파일 선택 창이 열립니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/main.cpp` | 시작할 파일 결정, 메시지 루프 |
| `src/MainWindow.*` | Win32 창과 입력 처리. mpv가 그릴 영상 자식 창을 가짐 |
| `src/ControlBar.*` | 영상 위에 합성되는 재생 바 (Direct2D + DirectComposition) |
| `src/ContextMenu.*` | 우클릭 메뉴 |
| `src/SettingsDialog.*` | 설정 창 |
| `src/InfoDialog.*` | 재생 정보 창 |
| `src/PlaybackInfo.*` | 재생 정보 창에 표시할 내용 수집 |
| `src/Shortcuts.*` | 단축키 목록과 기본값, 키 이름 |
| `src/FileAssociation.*` | 탐색기 연결 프로그램 등록과 해제 |
| `src/FileDialogs.*` | 파일 선택 창, 파일 종류 판별 |
| `src/Settings.*` | 설정 저장과 불러오기 |
| `src/SmiSubtitles.*` | 여러 언어가 든 SMI 파일을 언어별로 분리 |
| `src/MpvPlayer.*` | libmpv 호출을 모두 담당 |

## 조작

아래 키는 기본값이며, 우클릭 메뉴의 "설정 > 단축키"에서 바꿀 수 있습니다.

| 입력 | 동작 |
|---|---|
| `Space` | 재생/일시정지 (영상이 끝난 뒤에는 처음부터 재생) |
| `←` / `→` | 뒤로/앞으로 이동 (기본 5초) |
| `↑` / `↓`, 마우스 휠 | 볼륨 조절 |
| `Enter`, 더블클릭 | 전체화면 전환 |
| `Esc` | 전체화면 해제 |
| 영상 드래그 | 창 이동 (제목 표시줄을 끄는 것과 같음) |
| 파일 끌어다 놓기 | 해당 파일 재생 |
| 재생 바 | 재생/일시정지, 탐색, 볼륨, 전체화면 (슬라이더는 클릭 또는 드래그) |
| 우클릭 | 파일 열기, 자막/오디오, 재생, 영상, 설정 메뉴 |
| `S` / `A` | 자막/오디오 트랙 전환 |
| `,` / `.` / `/` | 자막 싱크 0.1초 빠르게/느리게/초기화 |
| 자막 파일 끌어다 놓기 | 현재 영상에 자막 추가 |
| `C` / `X` / `Z` | 배속 0.1 빠르게/느리게/원래대로 (0.25~4배) |
| `J` / `K` / `L` | 구간 반복 시작 지정 / 끝 지정 / 해제 |
| `F` / `D` | 다음/이전 프레임 |
| `Q` `W` / `E` `R` / `T` `Y` / `U` `I` / `O` `P` | 밝기 / 대비 / 채도 / 색조 / 감마 낮추기, 높이기 |
| `Backspace` | 영상 조정 초기화 |
| `[` / `]` / `\` | 음성 싱크 0.1초 빠르게/느리게/초기화 |
| `H` | 챕터 목록 (선택하면 그 챕터로 이동) |
| `F1` | 재생 정보 (재생, 파일, 시스템) |
| `F5` | 설정 |
| `1` / `2` / `3` / `4` | 창을 영상 원본의 50% / 100% / 150% / 200% 크기로 (모니터를 넘지 않는 만큼만) |

화면 비율과 회전은 우클릭 메뉴의 "영상"에서 바꿉니다. 챕터가 있는 영상은 탐색 막대에 챕터 경계가 노란 삼각형으로 표시됩니다.

새 파일을 열면 싱크, 구간 반복, 회전, 화면 비율은 초기화되고, 배속은 앱을 끌 때까지, 영상 조정은 다음 실행까지 유지됩니다.

영상을 열면 창이 영상의 원본 크기에 맞춰집니다. 모니터보다 큰 영상은 비율을 유지한 채 작업 영역에 맞춰지며, 최대화나 전체화면 중에는 창 크기를 바꾸지 않습니다.

영상과 이름이 같거나 이름을 포함하는 자막 파일은 자동으로 불러옵니다. 유니코드가 아닌 자막은 CP949로 읽으며, 다른 인코딩은 메뉴의 "자막 인코딩 > 자동 감지"로 읽을 수 있습니다. 한 SMI 파일에 여러 언어가 있으면 언어별 트랙으로 나누고 한국어를 먼저 선택합니다.

## 탐색기에서 열기

"설정 > 일반"에서 등록하면 영상 파일의 "연결 프로그램" 목록에 추가됩니다. 현재 사용자 레지스트리에만 기록하며 기존 기본 앱은 바꾸지 않습니다. 더블클릭으로 바로 열려면 Windows 기본 앱 설정에서 직접 지정하세요. 실행 파일을 옮겼다면 다시 등록해야 합니다.

이미 실행 중이면 새 창을 띄우지 않고 기존 창에서 엽니다.

## 설정

볼륨, 창 위치와 최대화 상태, 자막 인코딩, 영상 조정, 설정 창의 값은 `%APPDATA%\MoviePlayer\settings.ini`에 저장되어 다음 실행에도 유지됩니다.

우클릭 메뉴의 "설정"에서 바꿀 수 있는 항목:

- **일반:** 앞으로/뒤로 이동 간격, 탐색기 연결 등록과 해제
- **자막:** 글꼴, 크기, 외곽선 두께, 높이. ASS 자막처럼 자체 스타일이나 위치가 있는 자막은 그 설정을 우선합니다.
- **단축키:** 동작마다 키 하나(Ctrl, Shift, Alt 조합 가능). 이미 쓰는 키를 지정하면 이전 동작에서 옮겨 옵니다.

## 문제 해결

환경 변수 `MOVIE_PLAYER_MPV_LOG`에 파일 경로를 지정하면 mpv 로그를 남깁니다. 하드웨어 디코딩 사용 여부나 선택된 자막 트랙을 확인할 때 유용합니다.
